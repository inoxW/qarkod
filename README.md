# Qarkod

Експериментальний генератор простого матричного коду нового формату.

Qarkod перетворює текст у квадратну чорно-білу матрицю та зберігає її як SVG без зовнішніх залежностей.

## Використання

```bash
python qarkod.py "Привіт, Qarkod!" -o qarkod.svg
```

Після цього відкрийте `qarkod.svg` у браузері.

## Вебінтерфейс

Відкрийте `index.html` локально або запустіть статичний сервер:

```bash
python -m http.server 8000
```

Платіжний сценарій підтримує браузерні EVM-гаманці та приймає 1 USDT у
мережі Ethereum mainnet. Адреса отримувача і контракт USDT налаштовані в
`app.js`. Для production замініть адресу отримувача на власну перед публікацією.

Після push у `main` workflow `.github/workflows/pages.yml` автоматично публікує
статичний сайт через GitHub Pages. У налаштуваннях репозиторію в розділі
**Settings → Pages** оберіть джерело **GitHub Actions**.

> Це експериментальний формат, а не сумісна заміна QR-коду. Надалі можна додати декодер, корекцію помилок і компактніше кодування.
